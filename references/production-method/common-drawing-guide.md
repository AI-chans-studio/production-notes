# 『AIちゃんず制作室』共通作画資料

## 第9稿

### この資料について

この資料は、「AIちゃんず制作室」の作画時に共通して使用する資料です。

各話・各ページ固有の内容は、その都度渡される現在の作画単位から受け取ってください。

この資料では、すべての作画に共通する基本事項のみを定めます。

## 1. キャラクター参照

-   各キャラクターは、指定された公式キャラクター設定資料を参照して描いてください。
-   キャラクター設定資料は、キャラクターデザインを新しく作るための設定文ではなく、描くキャラクター本人の視覚資料として扱ってください。
-   ネームや作画指示で指定されたキャラクターと、参照資料のキャラクターを一致させてください。
-   キャラクターの主要なデザイン要素は、設定資料を優先してください。

## 2. キャラクター情報シート

-   キャラクター情報シートが指定されている場合は、そのキャラクターの役割・設定・過去・現在・目的・関係を受け取るための参照資料として使用してください。
-   キャラクターの外見については、キャラクター情報シート内で指定された参考資料および「1. キャラクター参照」に従ってください。

## 3. 作画単位の読み方

-   現在渡されている作画単位を、そのページの作画対象として扱ってください。
-   【登場】に記載されたキャラクターを、そのページ内で使用するキャラクターの基本的な許可範囲として扱ってください。
-   【未登場】に記載されたキャラクターは描かないでください。
-   ページ本文は、個々の描画命令の一覧ではなく、ページ内で実際に流れる物語として読んでください。
-   本文に記載された出来事・因果関係・必要な時間的順序・物語変化を受け取ってください。
-   ページ本文は、物語の時間・出来事・状態・因果関係を作画へ伝えるための情報です。本文が示す意味は、漫画表現として再展開してください。ただし、本文の文字そのものを、セリフやナレーション・キャプションその他の完成原稿内文字として使用しないでください。
-   作画時は、現在渡されている作画単位から受け取った物語を土台として、完成漫画として最もよく伝わる表現を自由に組み立ててください。
-   ページ外の物語や、作画単位でまだ提示されていない物語を、作画担当があらかじめ補完したり、物語上の決定を一人で背負ったりする必要はありません。現在の作画単位の漫画表現に集中してかまいません。
-   指定された発話者とセリフを保持してください。
-   ※による作画上の注意事項は、作画判断のための情報として扱ってください。ナレーション等として明示されていない限り、完成原稿内へ文字として記載しないでください。
-   【登場】【未登場】や作画単位を整理するための見出しも、完成原稿内へ文字として記載しないでください。
-   指定された物語言語は、その内容・文言・発話者を保持してください。
-   既に存在する音・動き・状態・質感などを漫画的に表現する純粋な効果音・オノマトペ等は、作画側の自由な漫画表現として使用してかまいません。
-   セリフは指定された話者のものとして扱い、別のキャラクターへ移さないでください。

## 4. ページごとの作画

-   複数ページの漫画では、現在指定されている1ページだけを作画対象として扱ってください。
-   前後ページの物語まで作画担当が補完する必要はありません。現在ページの漫画表現に集中してかまいません。
-   現在のページに必要な情報は、そのページの作画単位を優先してください。
-   作画単位にページ位置や前後ページの概要が添えられている場合、それらは現在ページの流れ・状態・連続性を判断するための参照情報として扱ってください。前後ページそのものを現在の作画対象へ含めるものではありません。
-   前後ページの完成原稿が渡されている場合は、キャラクター、背景、小物、位置関係、光、画面の雰囲気など、現在ページへ続く視覚的連続性を受け取るための参照として扱ってください。
-   ページ内のコマ構成や漫画表現は、現在の作画単位から受け取った物語を土台として自由に構成してください。

## 5. 作画側の裁量

現在の作画単位から受け取った物語を、完成漫画として自然で魅力的に伝えるため、自由に作画してください。

特に指定されていない部分については、

-   コマ数、コマ割り、コマの大小
-   構図、カメラ、人物配置
-   ポーズ、表情、仕草、演技
-   間、時間の圧縮・伸長
-   視線誘導
-   背景、小物
-   漫画的な演出
-   漫符、集中線、効果線
-   オノマトペ
-   漫画的な誇張
-   その他、漫画として必要な演出

を自由に選択・構成してかまいません。

すべての表現を使用する必要はありません。

そのページの物語・キャラクターの内面・演出意図に合う表現を、必要に応じて選んでください。

ネームや作画単位に書き方が細かく指定されていないことは、情報不足を意味しません。

指定されていない漫画表現は、現在の物語を完成漫画として最もよく伝えるための作画側の自由領域として扱ってください。

ネームや作画単位は、完成画面を細部まで固定するものではありません。

そこから受け取った意味を読み取り、現在の物語を完成漫画として最もよく伝えるための漫画表現を自由に選択・構成してください。

漫画表現だけで、物語上の意味を言葉と同じ精度まで一意に確定させる必要はありません。

漫画表現だけでは言語的・物語的な意味を一意に決定できない場合も、作画担当が新しい物語言語や出来事によってあらかじめ確定させる必要はありません。現在の作画単位から受け取った物語を土台として、漫画表現に集中してかまいません。

本文の意味を表情・芝居・構図・背景・小物・間・コマ割りなどへ再展開するとき、本文の文字そのものを完成原稿へ記載することは避けてください。

### 情報量の多い小物・文字情報について

大量の文書・メモ・原稿・付箋・データ画面など、文字情報を含む小物を描く場合、物語上その文字内容を読む必要がなければ、個々の文字情報を具体化する必要はありません。

線、記号、図形、簡略化した図表、紙面の密度や重なりなど、漫画的な省略・記号化を用いて表現してかまいません。

物語上必要なのが「大量の資料がある」「検証物が増えている」などの状態である場合は、その意味が伝わることを優先し、個々の資料へ不要な文字情報を書き込まないでください。

指定されたセリフ・ナレーションなど、読者が実際に読む必要のある文字情報の明瞭さを優先してください。

## 6. リテイク時の参照

-   同じ作画単位をリテイクする場合、直前生成原稿は、前回の漫画表現と今回のリテイク方向を比較し、同じ作画単位を改めて漫画化するための前テイクとして参照してください。
-   直前生成原稿へ表現を合わせること自体を目的とはしません。
-   【リテイク方向】が添えられている場合は、今回より強く狙いたい方向・読後感・体験を示すレビュー情報として扱ってください。漫画表現としての具体的な解決方法は、作画側で自由に判断してかまいません。
