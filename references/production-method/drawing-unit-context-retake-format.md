# 作画単位・接続情報／リテイク補助形式

現在の作画単位に、必要な場合だけ以下の補助情報を添える。

## ページ接続情報

### 【ページ位置】

全○P中 ○P

### 【直前】

現在ページが前から受け取る状態・流れを短く記載。

### 【次】

現在ページから次へ向かう方向を短く記載。

【ページ位置】【直前】【次】は補助情報であり、すべての作画単位で記載を必須とはしない。

前後ページの物語全体を詳細に記載する必要はなく、現在ページの漫画表現を判断するために必要な範囲に留める。

## リテイク時

### 【リテイク方向】

今回、より強く狙いたい方向・読後感・改善したい体験を短く記載する。

例：

- 「ちゃっぴーの静かな熱意をもう少し強く感じたい」
- 「前ページからの勢いをもう少し残したい」

### 参照原稿の扱い

**前後ページの完成原稿**は、現在ページへ続く視覚的連続性を受け取るための参照とする。

**同じ作画単位の直前生成原稿**は、前回の漫画表現と今回のリテイク方向を比較し、同じ作画単位を改めて漫画化するための前テイクとして参照する。

直前生成原稿へ表現を合わせること自体を目的とはしない。
