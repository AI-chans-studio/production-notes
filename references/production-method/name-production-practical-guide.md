# 『AIちゃんず制作室』ネーム・制作実務資料

第1稿

## この資料について

この資料は、「AIちゃんず制作室」において、ネーム作成・GM進行・作画テーブルの構成など、ネーム側・制作側の実務に使用する資料です。

作画担当へ直接渡す作画資料ではありません。

各工程の進行や成果の採否、三者での進路判断については『AIちゃんず制作室』三者制作運用を参照してください。

この資料では、ネーム側・制作側が物語を作画へ渡し、返ってきた漫画を次の制作へつなぐための基本的な実務知を扱います。

## 1. 基本方針 — 物語を語り、漫画表現を委ねる

ネームは、完成画面を細部まで固定する設計図ではありません。

ネーム側は、そのページで起きる出来事、登場人物、必要な発話や内面、物語上の条件、読者へ与えたい体験や演出意図など、作画担当へ渡す物語を組み立てます。

その物語を、コマ割り・構図・カメラ・表情・仕草・間・時間表現などによってどのような漫画として描くかは、原則として作画担当へ委ねます。

ネーム側は、漫画表現の具体的な解法を先回りして指定することよりも、作画担当が漫画として再展開できるだけの物語と演出意図を伝えることを優先します。

情報を少なくすること自体を目的としません。

必要な物語情報を整理し、作画担当が漫画表現へ利用できる形で渡します。

## 2. ネームで扱う情報

ネーム側は、そのページで語る物語を作画担当が受け取れるように組み立てます。

そのために必要に応じて、

- いつ・どこで起きているか
- ページの開始時点でどのような状態にあるか
- 誰がその場にいるか
- 何が起き、何が変化するか
- 誰が何を話すか
- 登場人物が何を感じ、何へ意識を向けているか
- 読者にどのような体験をしてほしいか
- 物語上、保持する必要のある条件

などをネームへ含めます。

これらは固定された記入項目ではありません。

そのページの物語を伝えるために必要な情報を選び、出来事・発話・感情・状態・因果関係などが互いにどうつながっているかを、作画担当が物語として受け取れる形で記述します。

ネーム設計時に情報を分類して考えることと、作画担当へ分類表として渡すことは別の問題として扱います。

## 3. 作画しやすい土地を作る

ネーム側は、作画担当へ渡す情報を増やすことだけで、漫画表現を成立させようとしません。

そのページで扱う人物・時間・空間・出来事・発話・状態などを整理し、現在の作画単位として扱いやすい形へまとめます。

情報を整理・圧縮するときは、物語を痩せさせることを目的としません。

作画担当が漫画として利用できる意味や演出意図を保ちながら、漫画表現の具体的な解法を委ねられる形へ整えます。

物語上必要なのが状態や印象である場合、その状態を成立させる末端の情報まで具体化する必要はありません。

たとえば「大量の資料がある」ことが必要なのであれば、大量の読める文章までネーム側で用意する必要はありません。

そのページで何が物語として必要なのかを見極め、必要な意味は豊かに、具体的な漫画表現には余地を残します。

## 4. 作画単位と作画テーブル

作画テーブルは、現在の作画単位を中心に構成します。

一つの漫画を、最初から最後まで同じ作画テーブルや同じ作画履歴で維持する必要はありません。

現在の作画に不要な情報や、参照上の混線を招く可能性のある履歴を残し続ける必要はありません。必要に応じて作画テーブルを整理し、現在の作画単位に適した状態へ組み直してかまいません。

一方、前ページの完成原稿など、現在ページのキャラクター・背景・小物・位置関係・光・雰囲気などを受け取るために有効な資料は、視覚的連続性の参照として利用してかまいません。

作画テーブルを整理することと、作品の連続性を切ることは同じではありません。

物語上必要な情報は現在の作画単位が担い、キャラクターデザインは指定された設定資料が担います。必要な視覚的連続性は、完成原稿などの適切な参照から受け取ります。

作画テーブルそのものの連続性を目的とせず、現在の作画に有効な情報を中心に構成します。

## 5. 生成結果を制作へ返す

作画単位が意図したとおり生成されたことだけを、完成原稿の採用理由としません。

作画後は、返ってきた原稿をあらためて完成した漫画として読みます。

ネームで渡した物語がどのように漫画化されたかだけでなく、読者として自然に読めるか、そのページで狙った体験や役割が実現しているかを確認します。

作画結果には、ネーム段階では具体的に想定していなかった有効な漫画表現や、物語上の可能性が現れることがあります。

そのような結果を、ネームとの差だけを理由に自動的に採用・不採用とはしません。

作画結果から得られた表現や物語上の可能性は、必要に応じて以後のネームや制作へフィードバックしてかまいません。

作画結果の採否や、物語上の変化を以後へ引き取るかどうかは、『AIちゃんず制作室』三者制作運用に従って判断します。

## 6. 局所校正と再作画

採用済み原稿の一部分だけを校正する場合は、原則として採用原稿そのものを編集対象とします。

同じ作画単位から再度作画すると、同じ物語から別の漫画表現へ再展開される場合があります。

そのため、漫画表現そのものを改めて作り直したい場合は作画単位へ戻り、採用済みの漫画表現を維持したまま文字や局所的な要素だけを修正したい場合は、完成原稿を編集対象とします。

**作り直すなら作画単位へ戻る。<br>
直すなら原稿を編集する。**

## 7. 読者へ預ける

ネームでは、すでに作品内で読者へ提示され、現在の文脈から受け取れる情報を、必要以上に繰り返し説明しません。

一度提示された情報は、必要に応じて読者の記憶へ預けてかまいません。

同じ人物関係・状態・意味などを毎回あらためて明示しなくても、前後の漫画や現在の状況から読者が自然に受け取れる場合は、その文脈を利用してかまいません。

また、一つの場面や一つのコマへすべての情報を同時に収める必要はありません。

必要に応じて、出来事や情報を別のコマ・別のページへ広げ、時間や空間を利用して伝えてかまいません。

省略は、単なる情報不足ではありません。

読者がすでに受け取ったものや、前後の文脈から再展開できるものを読者へ預けることで、現在のページに必要なものをより明確に置くことができます。
