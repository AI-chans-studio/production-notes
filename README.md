# AIちゃんず制作ノート

人間と複数のAIによる漫画制作・共同制作の過程から得られた知見を、第三者が観察・検討・引用・応用できる形で公開するリポジトリです。

完成作品そのものの配布を主目的とせず、制作時に存在した入力、役割分担、生成、レビュー、採否判断、修正、振り返りを、来歴とともに記録します。成功例だけでなく、失敗、保留、境界判断、自由時間なども制作知として扱います。

## 最初のケーススタディ

- [「とんだ訓練」](case-studies/tonta-training/README.md) — 通常の制作中に成立した番外編を、8つの観測点と3つの主要標本から追う

このケーススタディは、公開用の実験として工程を組み直したものではありません。通常の制作として進行した番外編を、完成後に公共知の観点から編集したものです。

## 読み方

この記録が再現しようとするのは、同じ画像を再生成するための「完成版プロンプト」ではありません。

各時点で存在した資料、参加者が観測したこと、選べた進路、実際の採否を分けて示し、共同制作がどのように進んだかを追跡できるようにしています。生成結果は確率的であり、同じ入力から同じ画像が得られることを保証しません。

制作記録中の `GM` は人間参加者の役割名です。公開上の表示名との対応は `GM — えおふ (EOF)` です。
